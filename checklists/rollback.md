# Rollback checklist
- [ ] Trigger and rollback decision owner recorded
- [ ] Freeze Pantheon writes and external jobs
- [ ] Preserve new Pantheon transactions and files
- [ ] Reconcile post-cutover writes with source host
- [ ] Restore compatible original code, database, files and config
- [ ] Revert DNS to documented source records
- [ ] Validate source site, forms, logins and integrations
- [ ] Notify stakeholders and record incident
